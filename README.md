# Контроль ИС

Локальное веб-приложение для просмотра и организации карточек товарных знаков. Главная страница знакомит с системой, а рабочий кабинет объединяет обзор, поиск, фильтры и подробные карточки.

## Возможности

- обзор количества карточек по состоянию;
- главная страница с переходом в рабочий кабинет;
- поиск по названию, правообладателю или номеру карточки;
- фильтры «Частично», «Заполнено» и «Черновик»;
- просмотр подробной карточки;
- добавление карточки в рабочем сеансе;
- восстановление исходного набора;
- адаптивный интерфейс для компьютера, планшета и телефона.

## Быстрый запуск

Понадобятся Node.js 22 LTS и npm. Минимальная поддерживаемая версия Node.js — 20.19.

Если установлен `nvm`, нужная версия выбирается автоматически из файла `.nvmrc`:

```bash
nvm install
nvm use
```

Откройте терминал в папке проекта и выполните:

```bash
npm ci
npm run dev
```

`npm ci` установит точные версии библиотек из `package-lock.json`. После запуска откройте адрес, указанный в терминале — обычно `http://localhost:3000`.

## Проверка и сборка

Все проверки одной командой:

```bash
npm run check
```

Готовую сборку можно открыть локально так:

```bash
npm run preview
```

## Данные и ограничения

Все названия, организации, регистрационные номера и заметки в исходном наборе вымышлены. Приложение не обращается к внешним сервисам. Изменения хранятся только в памяти браузера и исчезают после перезагрузки страницы.

Работа с реальными юридическими сведениями не поддерживается.

Подробное описание находится в [docs/functional-overview.md](docs/functional-overview.md), а последовательность ручной проверки — в [docs/test-scenarios.md](docs/test-scenarios.md).
