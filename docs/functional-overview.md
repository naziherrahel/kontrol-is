# Функциональное описание

## 1. Назначение

«Контроль ИС» — локальное приложение для просмотра небольшого каталога товарных знаков. Оно объединяет главную страницу, сводку, список и карточку записи в одном понятном рабочем пространстве.

Приложение поддерживает три основных сценария:

1. быстро увидеть состав текущего каталога;
2. найти нужную карточку;
3. просмотреть состав и состояние записи.

## 2. Разделы

### Обзор

Стартовый экран показывает количество всех, частично заполненных и черновых карточек. Каждый показатель открывает соответствующую часть каталога.

### Каталог

Раздел содержит восемь исходных записей. Пользователь может искать их по названию, правообладателю или номеру и применять фильтр состояния.

### Структура карточки

Раздел объясняет назначение основных полей и трёх условных состояний полноты заполнения.

### О системе

Раздел кратко объясняет назначение системы, состав интерфейса и локальное хранение изменений.

## 3. Карточка записи

Карточка содержит:

- название товарного знака;
- правообладателя;
- условный регистрационный номер;
- классы МКТУ;
- тип обозначения;
- состояние заполнения;
- рабочую заметку.

## 4. Добавление карточки

Форма принимает название, правообладателя и классы МКТУ. Новая запись получает статус черновика и доступна до перезагрузки страницы.

## 5. Техническое устройство

- React и TypeScript отвечают за интерфейс и локальное состояние;
- Vite используется для запуска и сборки;
- исходные записи находятся в `lib/catalog-data.ts`;
- основной интерактивный компонент находится в `components/catalog-app.tsx`;
- стили находятся в `app/globals.css`;
- сетевые запросы и постоянное хранилище отсутствуют.

## 6. Границы

Включённый набор сведений является вымышленным. Приложение не подключено к внешним системам, не обрабатывает реальные данные и не выполняет юридические операции. После обновления страницы оно возвращается к исходному состоянию.
