# Сценарии ручной проверки

## Сценарий 1. Переходы по разделам

1. Открыть стартовый экран.
2. По очереди выбрать четыре пункта бокового меню.
3. Вернуться на экран «Обзор».

Ожидаемый результат: выбранный пункт выделяется, содержимое меняется без перезагрузки страницы.

## Сценарий 2. Поиск

1. Открыть раздел «Каталог».
2. Найти запись по словам `Янтарная нить`.
3. Найти запись по номеру `CAT-TM-003`.
4. Ввести запрос, которого нет в списке.
5. Нажать «Очистить поиск».

Ожидаемый результат: список фильтруется, а для пустого результата появляется понятное сообщение.

## Сценарий 3. Фильтры

1. В каталоге выбрать «Частично».
2. Затем выбрать «Заполнено» и «Черновики».
3. Вернуться к фильтру «Все».

Ожидаемый результат: количество и состав строк соответствуют выбранному состоянию.

## Сценарий 4. Просмотр карточки

1. Открыть любую запись.
2. Проверить отображение правообладателя, классов, типа и заметки.
3. Закрыть карточку кнопкой и повторно открыть её.

Ожидаемый результат: диалог открывается поверх каталога и корректно закрывается.

## Сценарий 5. Структура карточки

1. Открыть раздел «Структура карточки».
2. Прочитать описание трёх групп полей.
3. Вернуться в каталог и открыть любую карточку.

Ожидаемый результат: поля открытой карточки соответствуют краткому описанию раздела.

## Сценарий 6. Добавление карточки

1. Нажать «Добавить карточку».
2. Заполнить три обязательных поля.
3. Добавить запись.
4. Найти её в каталоге.

Ожидаемый результат: новая запись появляется со статусом «Черновик» и существует до перезагрузки страницы.

## Сценарий 7. Узкий экран

1. Уменьшить ширину окна до размера телефона.
2. Открыть меню кнопкой «Меню».
3. Перейти в каталог и открыть карточку.

Ожидаемый результат: элементы не выходят за границы экрана, а основные кнопки остаются доступны.

## Сценарий 8. Сброс

1. Добавить новую запись.
2. Нажать «Сбросить изменения» в боковом меню.

Ожидаемый результат: восстанавливаются восемь исходных карточек.
